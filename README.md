# ClipBridge

ClipBridge is an open-source NFC + local Wi-Fi clipboard bridge for instantly sharing text, links, images and files between devices, with optional Windows and macOS desktop apps — no account, cloud service or mandatory app required.

## Project structure

- `ClipBridge_Arduino_UI/` — ESP32 firmware and device UI
- `desktop/` — Windows and macOS desktop application
- `README_DESKTOP` — Desktop application documentation
